
# Human Plasma Protein Binding Prediction using Machine Learning

## About the Project

This project focuses on predicting the fraction of chemicals that remains unbound in human plasma (Fub) using Machine Learning techniques.

It was completed as a group academic project based on a published research paper. The objective was to explore how machine learning models trained on pharmaceutical chemical data could be used to predict plasma protein binding in environmental chemicals.

## Models Implemented

We implemented and compared the following models:

- K-Nearest Neighbours (KNN)
- Support Vector Regression (SVR)
- Random Forest Regression
- Consensus model combining predictions from individual models

## Methodology

- Processed molecular descriptor data.
- Applied data preprocessing and feature handling.
- Trained and evaluated the machine learning models.
- Used five-fold cross-validation to assess model performance.
- Applied Principal Component Analysis (PCA) to study chemical-space coverage.

## Technologies Used

Python, NumPy, Pandas, Scikit-learn, Matplotlib, Jupyter Notebook.

## Research Paper

Based on:

Ingle et al. (2016), *Informing the Human Plasma Protein Binding of Environmental Chemicals by Machine Learning in the Pharmaceutical Space: Applicability Domain and Limits of Predictability.*

[DOI: 10.1021/acs.jcim.6b00291](https://doi.org/10.1021/acs.jcim.6b00291)
